# LIF Board — Leadership in the Field Engagements

MAXHUB мэдрэгч дэлгэц + PC / утсанд зориулсан LIF самбар.
**Сайт:** https://otpclif.mn · Сервер, Node.js, `.bat` файл шаардлагагүй — хөтчөөр нээгээд л ажиллана.

## Гол боломжууд
- **Dashboard** — 1–8 бүх хэсэг нэг дэлгэцэнд, гүйлгэх мөргүй (1366×768 – 4K).
- **1 Чухалчлах / 2 Чанар** — сарын 31 өдөр, 7 баганаар. Өдөр дээр дарах: хоосон → GREEN → RED → хоосон. Сараар хадгална.
- **3 Хурал** — 7 хоногийн хурал хийх хүмүүс, өндөр эрсдэлтэй ажлын төлөвлөгөө (текст + зураг), гараар бичих хэсэг.
- **4 Мэдээлэл** — `husnegt.xlsx` загвартай хүснэгт (Бямба–Баасан, нэр + 2 тэмдэглэгээ). 7 хоногоор хадгална.
  - Нүдэнд дарж нэр сонгоно, жижиг нүд: хоосон → ✓ → ✗.
  - **✎ Зурах** — хүснэгт дээр үзэг/хуруугаар (хар, улаан, ногоон) зурах, ↶ буцаах.
  - **⬆ Excel** — 7 хоногийн Excel хүснэгтийг шууд оруулна. **⬇ Excel** — 7 хоног + од + сарын G/R-ийг Excel-ээр татна.
- **5 Эрсдэл** — өдөр тус бүрийн Critical/Fatality Risk текст, эрсдэлийн бүртгэл, зураг/QR.
- **6 Хүмүүс / Онцлох ярилцлага** — жагсаалтыг Excel-ээс оруулна. ★ дарахад тухайн хүний мэдээлэл 2 сек гарна, **нэг хүнд нэг өдөрт нэг од**, нийт одны тоо хадгалагдана. Хүний зургийг 📷 дарж оруулна.
- **7 Хуваарь** — Main Schedule зураг.
- **8 Field Map** — талбайн зураг дээр SI/CP/CRM/PTHA… тэмдэг, үзгээр зурах.
- **Чиглүүлэгч** — 7 хоног бүр тусдаа; шинэ 7 хоногт өмнөхийг автоматаар авна.

## Ашиглах заавар
1. **Нээх** — MAXHUB / PC / утасны хөтөч дээр `https://otpclif.mn`.
2. **Нэвтрэх** — 🔑 Нэвтрэх → otpclicenses.mn-ийн имэйл, нууц үг. Нэг удаа нэвтэрвэл хадгалагдана.
3. **Засах горим** — дээд талын “👁 Харах горим” → PIN оруулна (анхдагч **1234**, ⚙ Тохиргооноос солино).
4. **Display Mode** — MAXHUB дээр дарахад бүтэн дэлгэц болж, засварын товчнууд нуугдана. “Гарах”-аар буцна.
5. **7 хоног / огноо** — ‹ › товч эсвэл огноо сонгоно. 7 хоног = Бямба–Баасан. Өдрийн хэсэг (5 Эрсдэлийн текст, од) өдрөөр, бусад нь 7 хоногоор хадгалагдана; өмнөх мэдээлэл устахгүй.
6. **Хадгалах** — өөрчлөлт бүр автоматаар хадгалагдана (cloud + төхөөрөмж). 💾 Хадгалах дарж шууд илгээж болно.
7. **Backup / Restore** — бүх 7 хоног, огнооны мэдээллийг JSON-оор татаж / сэргээнэ. 7 хоног бүр backup авахыг зөвлөж байна.

## Техникийн тайлбар
- Нэг файлтай статик сайт (`index.html`), GitHub Pages дээр.
- Өгөгдөл: otpclicenses.mn-тэй ижил Supabase, `lif_docs` хүснэгт (`lif_setup.sql`-ийг нэг удаа ажиллуулна). Зөвхөн админ засна, нэвтэрсэн хүн харна. Олон төхөөрөмж шууд синк хийнэ.
- Интернэт тасарвал төхөөрөмж дээрээ хадгалж, холбогдмогц cloud руу илгээнэ.
- Зураг автоматаар жижигрүүлж (≤1800px, хүний зураг ≤320px) хадгална — хэмжээний хязгааргүй.
